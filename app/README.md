# pdf_office (dự án Flutter)

Hướng dẫn đầy đủ (chức năng, cấu trúc, cài môi trường, lệnh, cách nhận việc T1…T10) nằm ở
[`README.md` ở thư mục gốc repo](../README.md).

Lệnh nhanh, chạy trong thư mục này:

```bash
flutter pub get
dart run tool/merge_arb.dart && flutter gen-l10n
flutter analyze && flutter test
```
