Quyết định thiết kế
Trang chủ: thay bố cục 3 ô bằng một thẻ chính đỏ "Ảnh sang PDF" ngang toàn bề rộng (minh hoạ ảnh → PDF) + hai thẻ phụ trắng có icon tô màu.
Tập tin: thanh tiêu đề đổi màu theo tab; tab "Tất cả" dùng màu mực than tím #25212B (tối: #2C2833) để không trùng màu đỏ của PDF và làm nổi các màu loại file; dùng sắc đậm hơn của cùng màu loại file (vd XLS #2E7D32, TXT #546E7A) để chữ trắng đủ tương phản. Icon file trong danh sách giữ đúng màu gốc.
Nút thống nhất kiểu chữ thường (Huỷ / OK / Xoá), dùng từ "file" thống nhất.
Trạng thái (Tweaks)
Tập tin: danh sách · đang quét · đang quét có file · thiếu quyền · băng xin quyền · trống · lỗi. Trang chủ: trống. Cài đặt: hiện "Thư mục lưu" (chỉ Android).
Icon loại file và minh hoạ trống/lỗi tự dựng bằng hình khối đơn giản, chỉ dùng nhãn chữ chung PDF/DOC/XLS/PPT/TXT. Tên file mẫu là tên giả.
